=====================================================================
 TRAFFIC LIGHT REAL-TIME SYSTEM - RUN GUIDE (6 LOCAL INTERSECTIONS)
=====================================================================

---------------------------------------------------------------------
1. BUILD (in a configured QNX SDP environment)
---------------------------------------------------------------------
make -C central_controller all PLATFORM=x86_64
make -C local_intersection_controller all PLATFORM=x86_64
make -C train_controller all PLATFORM=x86_64

Copy the binaries to /tmp on the QNX target:
  /tmp/central_controller
  /tmp/local_intersection_controller
  /tmp/train_controller

Each Local reads commands from its own keyboard, so run each process in
its own terminal (telnet/SSH session).


---------------------------------------------------------------------
2. SINGLE VM  (-l)
---------------------------------------------------------------------
# Terminal 1 - Central
/tmp/central_controller -l \
  --local-endpoint I1=traffic_local_controller \
  --local-endpoint I2=traffic_local_I2 \
  --local-endpoint I3=traffic_local_I3 \
  --local-endpoint I4=traffic_local_I4 \
  --local-endpoint I5=traffic_local_I5 \
  --local-endpoint I6=traffic_local_I6

# Terminals 2-7 - one Local per intersection
/tmp/local_intersection_controller -l -i I1 -n traffic_local_controller
/tmp/local_intersection_controller -l -i I2
/tmp/local_intersection_controller -l -i I3
/tmp/local_intersection_controller -l -i I4
/tmp/local_intersection_controller -l -i I5
/tmp/local_intersection_controller -l -i I6

# Terminal 8 - Train
/tmp/train_controller -l


---------------------------------------------------------------------
3. MULTI VM WITH GNS  (-g)
---------------------------------------------------------------------
There is no "--global-endpoint" option. --local-endpoint means "Local
intersection controller"; -g makes every lookup go through GNS.

# Central VM
gns -s &
/tmp/central_controller -g \
  --local-endpoint I1=traffic_local_controller \
  --local-endpoint I2=traffic_local_I2 \
  --local-endpoint I3=traffic_local_I3 \
  --local-endpoint I4=traffic_local_I4 \
  --local-endpoint I5=traffic_local_I5 \
  --local-endpoint I6=traffic_local_I6

# Every other VM - start the GNS client first
gns -c <central-node-name> &
/tmp/local_intersection_controller -g -i I1 -n traffic_local_controller
/tmp/local_intersection_controller -g -i I2
/tmp/local_intersection_controller -g -i I3
/tmp/local_intersection_controller -g -i I4
/tmp/local_intersection_controller -g -i I5
/tmp/local_intersection_controller -g -i I6
/tmp/train_controller -g

All Locals must use -g too. A Local started with -l is only visible on
its own VM and Central will not find it.


---------------------------------------------------------------------
4. SERVICE NAMES - RULES
---------------------------------------------------------------------
- -i I#  without -n       -> publishes traffic_local_I#
- no -i at all            -> runs as I1, publishes traffic_local_controller
- -n name                 -> publishes that name
- Every Local needs a DIFFERENT service name.
- Train connects to traffic_local_I1..I6. For I1 it also accepts the
  legacy name traffic_local_controller.

Train sends each crossing's PREEMPT/CLEAR to both of its Locals:
  P1 -> I1, I2    P2 -> I3, I4    P3 -> I5, I6


---------------------------------------------------------------------
5. LOCAL INTERSECTION CONTROLLER - OPTIONS
---------------------------------------------------------------------
/tmp/local_intersection_controller [-l | -g] [-i I1..I6] [-n service] [-h]

  -l                     Single-VM mode (same VM lookup)
  -g                     Multi-VM mode through GNS (default)
  -i, --intersection     Intersection ID I1..I6
  -n, --service          Service name to publish
  -h, --help             Show usage


---------------------------------------------------------------------
6. LOCAL INTERSECTION CONTROLLER - COMMANDS (type at "Message:")
---------------------------------------------------------------------
Traffic / pedestrians
  m              Switch fixed <-> sensor mode (manual override)
  n              Pedestrian request North-South
  e              Pedestrian request East-West
  x              Turn NS vehicle sensor on/off
  z              Turn EW vehicle sensor on/off

Train (local test)
  1              Start train on line 1
  2              Start train on line 2
  c              Clear train

Simulated time of day
  p              Peak      (07:00)
  o              Off-peak  (12:00)
  l              Night     (22:00)

Connection tests
  send-central   Send test message to Central
  send-train     Send test message to Train

Other
  r              Reset demo inputs
  <Enter>        Redraw screen
  q/quit/exit    Unregister service and exit

Traffic, train and time commands need ENABLE_DEMO_COMMANDS 1 and
ENABLE_TRAFFIC_SIMULATION 1 in local_intersection_controller/src/local_controller.h
(both are 1 now). With demo commands off, only send-central,
send-train and q work.

A Local only reacts to commands typed in its own terminal. To change
all six at once, use Central (e.g. mode-sensor all).


---------------------------------------------------------------------
7. CENTRAL CONTROLLER - COMMANDS
---------------------------------------------------------------------
  mode-fixed [I1..I6|all]     Request fixed timing
  mode-sensor [I1..I6|all]    Request sensor timing
  mode-temp I1 sensor 30      Request temporary mode for 30 s
  mode-revert I1              Cancel temporary mode
  coordinate I1 NS 0          Request fixed-cycle coordination
  sim-start I1 / sim-stop I1  Start / stop Local simulation
  sim-time I1 07:00           Set Local simulated time
  status                      Show a snapshot
  watch                       Live view (Enter exits)
  commands / faults / events  Show requests, fault alerts, recent events
  help / quit                 Show usage / exit

Central options: -s 1..60 sets max status age in seconds (default 5).
For the demo, do not pass --schedule, so each Local's simulated clock
controls time-of-day policy.


---------------------------------------------------------------------
8. CHECK IT WORKS
---------------------------------------------------------------------
1. In Central run: status   (all six I1..I6 should show connected)
2. Run: mode-sensor all     (every Local screen should change mode)
3. In a Local type: send-central   (Central should log the message)
4. Stop a Local with q and check Central reports it lost.
